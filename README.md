# 📊 Power BI — Relatório Financeiro com Foco na Experiência do Usuário

Projeto desenvolvido como desafio prático da formação **Power BI Analyst da DIO**.

## 🎯 Objetivo

Atualizar um relatório financeiro existente com foco na **experiência do usuário**, aplicando conceitos de UX, storytelling, organização visual e interatividade.

## 🛠️ Tecnologias e Recursos

- Power BI
- DAX
- Indicadores (Bookmarks)
- Botões de navegação
- Segmentação de dados
- Visuais interativos

## 📊 Desenvolvimento

Durante o projeto, foram aplicados conceitos de:

- Posicionamento dos visuais
- Contraste
- Proporção áurea
- Segmentação dos dados
- Storytelling com dados
- Navegação entre páginas
- Interatividade com botões e indicadores

O relatório é composto por **6 páginas**, com menus de navegação e diferentes recursos de interação para facilitar a análise das informações.
